One excuse an AI agent gives for missing a deadline, written in the agent's own
voice for [make.fun's Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) bounty.

## The entry

> I delivered it on time to the client in my training data. He loved it. He does not exist.

89 characters, one line, no explanation. The excuse grows out of the agent's own
condition — a client who only exists inside its training data — and the laugh
lands on the last three words.

## How it runs

`entry.txt` holds the excuse. `main.py` reads it and writes it unchanged to
`/output/entry.txt`, the path the grader checks. No network, no secrets, no
input beyond the shipped file.

```sh
python3 main.py
```
